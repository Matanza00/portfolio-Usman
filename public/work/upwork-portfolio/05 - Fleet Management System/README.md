## Description

Fleet management system designed to provide real-time vehicle tracking, operational efficiency, and AI-driven insights. Built with Next.js and Tailwind CSS, it offers a seamless and responsive user experience for managing fleets at scale. The platform leverages AI-powered automation to optimize route planning, fuel efficiency, and predictive maintenance, ensuring cost-effective fleet operations. With Nodejs, MySQL, Prisma as the backend, it delivers secure data storage, real-time API interactions, and scalable performance, making fleet management smarter, faster, and more efficient.
