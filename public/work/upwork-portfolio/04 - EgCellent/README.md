## Description

This project simplifies farm financial management by providing an easy, ledger-based system designed specifically for farmers. It allows farm managers to track egg sales, feed, medicines, transport costs, and payments from a single, user-friendly dashboard.

The system replaces complex accounting terms with simple actions, guided onboarding, and quick input buttons, making it easy even for non-technical users. The result is clearer finances, fewer errors, and faster daily operations for farms.
