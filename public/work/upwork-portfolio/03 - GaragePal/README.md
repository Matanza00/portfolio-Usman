## Description

GaragePal is an online platform designed to connect drivers with trusted automotive service providers. It offers an access to a network of vetted garages. Users can search for nearby service providers, book appointments, and manage their vehicle maintenance through the platform.
Additionally, GaragePal has a presence in Qatar and Canada, where it operates as the first garage e-marketplace in the country. 
NextJs, NodeJs, Tailwind , Material UI , My SQL , Prisma , CMS , Admin Dashboard , Admin Panel , API Integration , Google Map Integration , Google OAuth , Google 2FA, Node Mailer, Chat Bot.
